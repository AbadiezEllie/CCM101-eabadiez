# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended because it offers flexible and scalable services that can accommodate a startup's limited budget and future growth. The company can begin with smaller cloud resources and increase them as the mobile application gains more users. AWS also provides many services that can support mobile application development and deployment. This makes it a suitable choice for a startup that expects rapid growth.

### Recommended Services

1. **Amazon EC2** – Provides scalable virtual servers for running application components.
2. **Amazon S3** – Provides scalable storage for images, files, and other application data.
3. **Amazon RDS** – Provides a managed relational database for storing application information.

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the recommended platform because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, which can make cloud migration and identity management easier. The university can connect its existing infrastructure with Azure services while maintaining centralized access management. This allows the university to gradually migrate services to the cloud.

### Recommended Services

1. **Azure Virtual Machines** – Allows the university to run Windows-based servers in the cloud.
2. **Microsoft Entra ID** – Provides cloud-based identity and access management.
3. **Azure Blob Storage** – Provides scalable storage for documents, files, and other university data.

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud Platform is recommended because it provides strong Artificial Intelligence and Machine Learning capabilities. It also offers high-performance computing resources that can support demanding research workloads. Google Cloud provides specialized AI and machine learning tools that can help researchers develop and train models. Its support for Kubernetes also makes it suitable for deploying containerized AI applications.

### Recommended Services

1. **Google Compute Engine** – Provides scalable virtual machines for high-performance computing workloads.
2. **Google Kubernetes Engine (GKE)** – Provides a managed environment for running containerized AI applications.
3. **Vertex AI** – Provides tools for developing, training, and deploying machine learning models.

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended because it provides a large global infrastructure suitable for a multinational e-commerce company. Its services can support highly available applications and automatically scale resources based on customer demand. AWS also provides multiple Regions and Availability Zones that can help improve application availability and reliability. These capabilities make AWS suitable for an online shopping platform serving customers around the world.

### Recommended Services

1. **Amazon EC2** – Provides scalable computing resources for running the e-commerce application.
2. **Amazon S3** – Provides highly scalable storage for product images, files, and other data.
3. **Elastic Load Balancing** – Distributes incoming traffic across application resources to improve availability and performance.
