# Reflection

Cloud computing is the backbone of modern IT, and this mission showed me exactly why.

Completing this cloud computing mission helped me understand how cloud platforms can be used to provide computing resources and services. Among the three major cloud platforms, **AWS impressed me the most** because of its wide range of services and its flexibility for different types of applications and workloads. Learning about Amazon EC2 also helped me understand how a Linux server can be migrated to a cloud environment without needing to maintain the physical hardware.

AWS, Azure, and GCP have many similarities. All three provide cloud computing services that allow organizations to use computing resources over the internet. They all offer virtual machine services, storage, networking, databases, security features, and other tools for developing and deploying applications. For example, a Linux server can be hosted using **Amazon EC2**, **Azure Virtual Machines**, or **Google Compute Engine**. Although the platforms have similar services, their features, pricing, performance, and available tools may differ.

Business requirements strongly influence cloud platform selection. Organizations need to consider their budget, workload, security requirements, scalability, performance, existing technologies, and the skills of their employees. A company should therefore choose a cloud platform based on what best fits its specific needs rather than simply choosing the most popular platform.

Stepping into the role of a Cloud Solutions Consultant drove this home. Before recommending any solution, I learned to first understand the customer's needs — checking a server's OS, CPU, memory, and disk resources to match it with the right cloud service.

Finally, this mission improved my GitHub Cloud Computing Portfolio by allowing me to document my Linux investigation, cloud migration options, terminal screenshots, and reflection. It also gave me practical experience using Linux commands and connecting server resources to real cloud services. Overall, the mission helped me become more confident in analyzing infrastructure and thinking about cloud solutions from a practical and business perspective.
