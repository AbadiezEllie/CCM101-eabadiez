# GCP Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, artificial intelligence, data analytics, and application development.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of Regions and Zones. Regions are geographic locations, while Zones are deployment areas within Regions. This infrastructure allows organizations to deploy applications and services across different locations for improved performance and reliability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and configure resources, monitor applications, manage projects, and control access permissions.

## Four (4) Core Services

1. **Compute Engine** – Provides virtual machines for running applications.
2. **Cloud Storage** – Provides scalable object storage for data and files.
3. **Cloud SQL** – Provides managed relational database services.
4. **Google Kubernetes Engine (GKE)** – Provides a managed environment for running containerized applications.

## Three (3) Advantages

1. **Data and AI Capabilities** – Provides powerful services for data analytics and artificial intelligence.
2. **Scalability** – Cloud resources can be scaled according to workload requirements.
3. **Global Infrastructure** – Google Cloud provides infrastructure across many geographic locations.

## Typical Enterprise Use Cases

GCP is commonly used by enterprises for application hosting, big data analytics, artificial intelligence and machine learning, containerized applications, database management, website hosting, and large-scale data processing.
