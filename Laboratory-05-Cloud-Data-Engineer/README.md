# Laboratory 05 – Cloud Data Engineer

## Mission Overview
This laboratory activity focuses on deploying an S3-compatible object storage server using MinIO. 

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy MinIO as an S3-compatible Object Storage server using Docker.
- Access the MinIO web console via port forwarding.
- Create a storage bucket and upload objects to the cloud.
- Document cloud storage operations using Markdown.
- Expand a professional GitHub Cloud Computing Portfolio.

## Tools Used
- KillerCoda Playground (Ubuntu/Docker environment)
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned
- Understanding cloud storage types and their use cases.
- Deploying containerized services with Docker.
- Managing object storage through a web interface.
- Creating and organizing buckets for cloud data.
- Writing structured technical documentation in Markdown.
- Strengthening GitHub portfolio with cloud engineering projects.
